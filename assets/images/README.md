# Images

Drop your real photos in here with these filenames and they'll automatically
replace the placeholder blocks on the site:

- `profile.jpg` — the About Me polaroid photo
- `gallery/iphone-1.jpg`, `gallery/iphone-2.jpg` — "From my iPhone"
- `gallery/music-1.jpg` through `gallery/music-4.jpg` — "Music Marketing"
- `gallery/ugc-1.jpg` — "UGC"
- `gallery/san-diego.jpg` — "San Diego (UGC)"
- `gallery/beach.jpg` — "Beach (UGC)"
- `gallery/rodeo.jpg` — "Rodeo (UGC)"

Add or rename entries in `index.html` / `assets/css/style.css` freely — the
`data-placeholder` attribute on each `.placeholder-photo` element just notes
which file it's expecting.
